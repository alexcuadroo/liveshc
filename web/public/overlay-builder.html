    Cómo añadirlo en OBS
    1. En Fuentes pulsa + → Navegador.
    2. Pega la URL en el campo URL.
    3. Tamaño sugerido: 800 × 120. Deja el CSS personalizado por defecto (fondo transparente).
    4. Opcional: marca Actualizar navegador cuando la escena se active.
