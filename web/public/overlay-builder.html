    Cómo añadirlo en OBS Studio
    1. En OBS, dentro de tu lista de Fuentes, haz clic en + → Navegador.
    2. Pega la URL generada en el campo URL.
    3. Configura la resolución recomendada: 1000 × 140. Mantén el CSS personalizado por defecto.
    4. Recomendado: activa la opción «Actualizar navegador cuando la escena se active» para sincronización limpia.
